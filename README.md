# Gaia — Persistent Unbounded Multi-Race AI Civilization Engine

A persistent, local-first, stylized anime-fantasy AI civilization simulation with no hard population cap, scaling organically from initial founders to 10,000+ autonomous neural-network agents across 4 distinct races (HUMAN, ELF, DRAGON, BEASTHUMAN) and 2 biological genders (BOY / GIRL).

Governed by the Divine Family Hierarchy: God (Admin / User), World Goddess (Global Critic / Error Solver), and 4 Racial God-Mothers.
